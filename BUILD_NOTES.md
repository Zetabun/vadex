# Build notes — v1.23.0

Published from `main` as a static GitHub Pages site. `index.html` imports the 78 readable modules under `modules/`; its import map uses a release version query so browsers pick up changed modules after deployment. Existing saves migrate through schema 14. Shield Capacity now opens at Wave 3 and recharge upgrades at Wave 6; existing shield levels use the new capacity curve. The blue shield bar sits above the green hull bar when equipped. The left combat status tray can expand for live and fitted DPS, passive repair, shield recharge, credits, buffs, debuffs and boons. The collector shows the single Scrap payout when it reaches a drop. Selection and callouts are disabled on non-editable game controls, while save and debug text fields remain selectable. The test gate is `python tools/run_release_gates.py`.
