# Build notes — v1.24.0

Published from `main` as a static GitHub Pages site. `index.html` imports the 78 readable modules under `modules/`; its import map uses a release version query so browsers pick up changed modules after deployment. Existing saves migrate through schema 14. Shield Capacity opens at Wave 3 and recharge upgrades at Wave 6. The blue shield bar sits above the green hull bar when equipped. A compact Systems drawer above the bars now holds smaller active abilities, Foundry supplies, effect lists and combat rates. Overdrive appears as one action icon, with its active timer shown as text. The collector shows the single Scrap payout when it reaches a drop. Selection and callouts are disabled on non-editable game controls, while save and debug text fields remain selectable. The test gate is `python tools/run_release_gates.py`.
