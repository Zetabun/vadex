# Build notes — v2.25.1

Published from `main` as a static GitHub Pages site. `index.html` imports the readable modules under `modules/`; the import map uses a release version query so browsers pick up changed modules after deployment (`python tools/build_importmap.py <version>`, which also rebuilds the in-game Updates history, `modules/data/updates.js`, from `CHANGELOG.md`). v2 saves use the keys `v2_main`, `v2_backup` and `v2_sandbox`, so a player's v1 save is left untouched; pilots with a v1 save get a one-time salvage gift based on their best v1 wave. The page links `manifest.webmanifest` and the icons in `icons/` for home-screen installs. The global boards run on their own Cloudflare Worker (`api/`, deployed with wrangler), apart from the site. The test gate is `python tools/run_release_gates.py`; every release keeps a save in `tests/saves/`, and the gate refuses a release without its dated changelog entry and version stamps (see `AGENTS.md`, "Before every push").
