# Build notes — v1.21.0

Published from `main` as a static GitHub Pages site. `index.html` imports the 78 readable modules under `modules/`; its import map uses a release version query so browsers pick up changed modules after deployment. The old inline base64 bundle is no longer the deployed source of truth. Existing saves migrate through schema 14. Players who previously reached Wave 41 retain the Lunar Passage. Ore, Bars, refined upgrades and projects survive Rewind; specialist drones belong to the run. Paused intermission management fills the viewport, Ship Level has a roadmap, and weapon readouts use combat configurations. The test gate is `python tools/run_release_gates.py`.
