# Current state — v1.19.0

Last Orbit is a live orbital-defence idle/RPG game with Credits, upgrades, weapons, modules, drones, abilities, research, production systems, Ship XP, Rewind, and offline rewards. Ship Loadout fills the app viewport and pauses combat while open. Its empty paper-doll sockets have no equipment artwork. Credits use `¢`.

The full-screen Skill Tree is a connected, draggable pilot-core web with branching paths, cross-links, tap-to-inspect nodes, and a separate unlock action. A perk needs at least one rank in an adjacent node; planned outer nodes show where the web can grow but cannot be purchased. It opens at Wave 8, with deeper tiers at Waves 12 and 20. Its 12 capped perks award one point at Ship Levels 3, 5, 7, and each second level thereafter. All points can be reset freely. Skills, points and Ship XP belong to the run and reset on Rewind. Boon chips open compact effect details, and Arsenal links directly to Loadout.

Wave 15 unlocks Drone Bays and a one-at-a-time specialist choice: Mining extracts extra Ore from enemies, while Target Painter applies up to 16% bonus damage. Hold mode mines the selected discovered material. Early refined Bars add modest permanent ship bonuses, and smelter automation unlocks at Waves 12 and 22. The Wave 30 Lunar Passage asks for Palladium Ore, an Iridium Bar and a Boss Core; Wave 40 must be cleared before entering the Graveyard. The route project and mined materials persist across Rewind. Existing Wave 41+ saves are grandfathered into the passage by schema 14 migration.
