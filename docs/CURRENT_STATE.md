# Current state — v1.18.1

Last Orbit is a live orbital-defence idle/RPG game with Credits, upgrades, weapons, modules, drones, abilities, research, production systems, Ship XP, Rewind, and offline rewards. Ship Loadout fills the app viewport and pauses combat while open. Its empty paper-doll sockets have no equipment artwork. Credits use `¢`.

The full-screen Skill Tree is a four-direction pilot-core map with tap-to-inspect nodes and a separate unlock action. It opens at Wave 8, with deeper tiers at Waves 12 and 20. Its 12 capped perks award one point at Ship Levels 3, 5, 7, and each second level thereafter. Ranks have small caps and prerequisites; all points can be reset freely. Skills, points and Ship XP belong to the run and reset on Rewind. Existing saves migrate to schema 13. The active onboarding sequence includes a Skills lesson; completed earlier tutorials remain complete. Boon chips now open compact effect details, and Arsenal links directly to Loadout.
